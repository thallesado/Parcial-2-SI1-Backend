# Resources Laravel

Esta carpeta contiene recursos internos de Laravel que no son API Resources. En este proyecto se usa principalmente para vistas Blade.

## Subcarpetas

- `views/`: plantillas HTML de Laravel.

## Uso actual

Se usa para generar:

- La boleta PDF de inscripcion publica.
- Los reportes PDF administrativos.
- Los archivos `.xls` compatibles con Excel.
