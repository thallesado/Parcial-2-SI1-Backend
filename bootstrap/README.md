# Bootstrap Laravel

Esta carpeta contiene la configuracion inicial de arranque de Laravel.

## Archivos

- `app.php`: registra rutas, middleware y manejo centralizado de excepciones.
- `providers.php`: proveedores de Laravel.

## Que se modifico en este proyecto

En `app.php` se agrego manejo de errores para que el frontend reciba JSON claro en lugar de errores tecnicos largos.

## Cuando tocarlo

Solo cuando necesites cambiar configuracion global de Laravel, manejo de errores, middleware globales o rutas base.
